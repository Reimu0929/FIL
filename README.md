# フォトビューア

フォルダ別に写真を選び、全画面で表示する軽量アプリ(Android 5.0 以上、依存ライブラリなし)。

- フォルダ一覧 → タップでタイル(サムネイル)表示、ファイル名の昇順 → タップで全画面表示(ナビゲーションバーも非表示)
- ピンチで拡大縮小(拡大中はドラッグで移動)
- 左右スワイプ、または画面の左1/3・右1/3タップで前後
- タイルの大きさは「サイズ」ボタンで 小/中/大
- サムネイルはディスクに保存(SDカードがあればSD)
- 中央タップでファイル名・フォルダ名・枚数
- 長押ししても写真は切り替わりません
- 表示中は画面が消えません

## 設定(右上の3ドット → 設定)
- サムネイルと全画面用キャッシュのファイル数・ディスク使用量を種類別に表示
- アプリ全体のRAM使用量(概算)、サムネイルのRAMキャッシュ使用量を表示
- ディスクキャッシュの上限調整(最大10GB)と全削除
- 手動生成は既定で未作成のキャッシュだけを対象にし、必要ならキャッシュ済みの写真も全件再生成可能
- サムネイルのキャッシュ生成(大・中・小を全フォルダ分)、生成状況の表示・停止
- 全画面用ディスクキャッシュの自動生成: オフ / アプリ起動時に全フォルダ / フォルダを開いたとき
- 全画面用ディスクキャッシュを手動で全フォルダ分生成(進行状況の表示・停止)
- 全画面で前後の写真を先読みする枚数(左右それぞれ最大100枚、合計最大200枚。ディスクへ準備し、RAMには上限内で保持)、タイル画面の先読み量(ページ数)
- 写真画面にキャッシュ枚数とRAM使用量を表示
- 画面下部にアプリのバージョン(1.4)を表示

全画面用キャッシュは、画面サイズに合わせて縮小したJPEGとしてサムネイルとは別の `full` フォルダに保存されます（サムネイルは `thumbs` フォルダ）。
写真をメモリに全部載せるわけではないので、枚数が多くてもメモリを圧迫しにくくなっています。

## APKの作り方(GitHub Actions、PCに何も入れなくてよい)
1. GitHubで新しいリポジトリを作り、このフォルダの中身(`.github` を含む)をすべてアップロードする
2. 「Actions」タブ → build → 完了を待つ
3. 実行結果の「Artifacts」から `PhotoViewer-apk` をダウンロードして展開し、`app-release.apk` を端末に入れる

## 署名について
`debug.keystore` をリポジトリに含め、`debug` / `release` の両ビルドでそれを使うようにしてあります。
配布物は `release` ビルド(`debuggable` なし)ですが、署名鍵は今までと同じ `debug.keystore` なので、上書きインストールできます。
以前のAPKから切り替えるときだけ、署名が違うため一度アンインストールしてから入れてください。
