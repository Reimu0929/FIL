# フォトビューア

フォルダ別に写真を選び、全画面で表示する軽量アプリ(Android 5.0 以上、依存ライブラリなし)。

- フォルダ一覧 → タップでタイル(サムネイル)表示、ファイル名の昇順 → タップで全画面表示(ナビゲーションバーも非表示)
- ピンチで拡大縮小(拡大中はドラッグで移動)
- 左右スワイプ、または画面の左1/3・右1/3タップで前後
- タイルの大きさは「サイズ」ボタンで 小/中/大
- サムネイルはディスクに保存(SDカードがあればSD)
- 中央タップでファイル名・フォルダ名・枚数
- 長押ししても写真は切り替わりません
- 表示中は画面が消えません

## 設定(右上の3ドット → 設定)
- サムネイルの全キャッシュ生成(大・中・小を全フォルダ分)、生成状況、キャッシュのサイズ、上限の調整(最大10GB)、全削除
- 全画面用キャッシュの先読みタイミング: オフ / 起動時に全フォルダ / フォルダを開いたとき
- 全画面用キャッシュを手動で全フォルダ分生成(進行状況の表示・停止)
- 全画面の先読み枚数(左右N枚、最大100枚)、タイル画面の先読み量(ページ数)
- 読み込み済みの枚数を画面に表示
- 画面下部にアプリのバージョン(1.3)を表示

全画面用キャッシュは、画面サイズに縮小したJPEGとしてサムネイルと同じフォルダに保存されます。
写真をメモリに全部載せるわけではないので、枚数が多くてもメモリを圧迫しにくくなっています。

## APKの作り方(GitHub Actions、PCに何も入れなくてよい)
1. GitHubで新しいリポジトリを作り、このフォルダの中身(`.github` を含む)をすべてアップロードする
2. 「Actions」タブ → build → 完了を待つ
3. 実行結果の「Artifacts」から `PhotoViewer-apk` をダウンロードして展開し、`app-debug.apk` を端末に入れる

## 署名について
`debug.keystore` をリポジトリに含め、ビルド時にそれを使うようにしてあります。
そのため、GitHub Actions で何度ビルドしても同じ署名のAPKになり、上書きインストールできます。
以前のAPKから切り替えるときだけ、署名が違うため一度アンインストールしてから入れてください。
